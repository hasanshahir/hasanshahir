## About Me

CS student at **NED University (`NED'29`)**, building production web platforms, AI/RAG systems, and algorithmic engines at **[hkh.agency](https://hkh.agency)**.

I care about end-to-end engineering — from low-level graph routing in C++ to high-concurrency Next.js + Postgres backends and grounded LLM pipelines:

`Idea → Architecture → Backend & DB → AI/RAG → UI → CI/CD → Ship`

- 🔭 Building **Baatcheet**, an Urdu-first AI customer support platform grounded strictly in business docs via RAG
- ⚡ Shipping **Eventr**, a real-time developer & tech event hub across 20 regional Pakistani desks
- 🧪 Engineering the official web & research platform for **AIR Lab @ NED University**
- 🧩 Practicing algorithms, graph theory, and competitive programming on **Codeforces**

## Featured Projects

| Project | What it does | Stack |
|---|---|---|
